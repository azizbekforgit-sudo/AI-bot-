# Claude Desktop Assistant

Голосовой ассистент для Windows в духе JARVIS. Вы говорите «**Клод**» и задачу, а ассистент выполняет её на вашем компьютере.

- **Уши и рот** — само приложение. Кодовое слово, распознавание русской речи и озвучка работают **локально**: звук с микрофона никуда не отправляется.
- **Мозг** — [Claude Code](https://docs.claude.com/en/docs/claude-code/overview), в который вы вошли со своей **подпиской Claude Pro**. API-ключ не нужен.
- **Руки** — простые действия (открыть программу или сайт, время, поиск файлов, состояние железа) ассистент делает сам, мгновенно и без расхода лимитов. Всё остальное (код, файлы, проекты, «почему не запускается») выполняет Claude Code через свои инструменты и проверяет результат.

```
 «Клод, …»  ──► микрофон ──► Vosk (офлайн) ──► текст
                                               │
                     простая команда? ── да ──► локальные инструменты ──┐
                                               │ нет                    │
                                               ▼                        ▼
                              claude -p (подписка Pro) ──► ответ ──► экран + голос Windows
                              с ограниченными правами
```

## Возможности

| | |
|---|---|
| Активация | кодовое слово «клод» (настраивается), горячая клавиша **Ctrl+Alt+Space**, кнопка «Говорить», двойной хлопок (выключен по умолчанию) |
| Речь | русская речь офлайн (Vosk), ответы голосом Windows (SAPI), остановка речи — Esc, кнопка «Замолчать», команда «стоп» |
| Компьютер | открыть/закрыть программу (с проверкой, что процесс действительно запустился/закрылся), открыть сайт, поиск в Google, поиск файлов в разрешённых папках, скриншот (если разрешён) |
| Claude Code | многошаговые задачи: код, правка файлов, запуск тестов, git, разбор ошибок — в пределах выбранного уровня автономии |
| Железо | загрузка CPU, температура CPU (если доступна), GPU: загрузка, видеопамять, температура (NVIDIA — через NVML; AMD/Intel — счётчики Windows), RAM, диски, батарея, процессы |
| Безопасность | 3 уровня автономии, подтверждение рискованных действий, вечный запрет опасных команд, **экстренная остановка** (кнопка «СТОП» или **Ctrl+Alt+X**) |
| Память | только то, что вы явно попросили запомнить; просмотр, правка, экспорт и удаление на вкладке «Память» |
| Windows | значок в трее, автозапуск при входе (по желанию), защита от второй копии |

## Требования

- Windows 10 (1709+) или Windows 11.
- Python 3.10–3.13 ([python.org](https://www.python.org/downloads/), при установке отметьте *Add python.exe to PATH*).
- Подписка **Claude Pro** (или Max) и установленный **Claude Code**.
- Микрофон — для голоса. Без него работает текстовый ввод.

## Установка

1. Скачайте проект (`git clone` или ZIP) в удобную папку, например `C:\Users\ИМЯ\ClaudeAssistant`.
2. Откройте PowerShell в этой папке и выполните:
   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts\setup.ps1
   ```
   Скрипт создаст `.venv`, установит зависимости, скачает модель русской речи (~45 МБ), проверит Claude Code и русский голос Windows и создаст ярлык в меню «Пуск». Права администратора не нужны, системные настройки не меняются.
3. Чтобы ассистент запускался при входе в Windows, добавьте ключ: `scripts\setup.ps1 -Autostart`. Это можно включить и позже в настройках.

### Установка Claude Code и вход по подписке

```powershell
irm https://claude.ai/install.ps1 | iex
```
Затем откройте **новый** терминал, выполните `claude` и войдите в аккаунт **Claude Pro** (вход через браузер). Если установщик попросит Git for Windows, установите его ([git-scm.com](https://git-scm.com/download/win)).

Проверка: в приложении откройте «Настройки → Мозг — Claude Code → Проверить».

**Про оплату.** С подпиской запросы входят в её лимиты, отдельных списаний нет. Если лимит исчерпан, ассистент скажет об этом, и лимит восстановится сам. **Важно:** если в системе задана переменная `ANTHROPIC_API_KEY`, Claude Code стал бы использовать платный API. Поэтому ассистент по умолчанию убирает эту переменную при запуске Claude (галочка «Использовать подписку Claude Pro» в настройках).

## Запуск

- Ярлык **Claude Desktop Assistant** в меню «Пуск», или
- `scripts\run.ps1` (для диагностики: `scripts\run.ps1 -Console`).

Окно можно закрыть: ассистент продолжит работать в трее. Выход — правой кнопкой по значку в трее → «Выход».

## Как пользоваться

Скажите «**Клод**», дождитесь сигнала и индикатора «Слушаю», затем произнесите команду. Можно сказать всё сразу: «Клод, открой блокнот».

| Сказать | Что произойдёт |
|---|---|
| «который час», «какое сегодня число» | ответ сразу, без Claude |
| «открой блокнот / vs code / калькулятор» | запуск и проверка, что программа открылась |
| «закрой блокнот» | вежливое закрытие (несохранённые данные не теряются) |
| «открой ютуб», «открой сайт habr.com», «загугли погоду в Москве» | браузер |
| «найди мой проект бот» → «открой первый» | поиск в разрешённых папках |
| «как там видеокарта?», «насколько загружен процессор», «сколько места на диске», «заряд батареи» | живые данные датчиков |
| «запомни, что мой проект лежит в D:\code», «что ты помнишь», «забудь про …» | память |
| «стоп» / «хватит» | замолчать и отменить текущую задачу |
| «новый разговор» | забыть контекст беседы (сохранённая память остаётся) |
| всё остальное, например «почему не запускаются тесты в моём проекте?» | задача уходит в Claude Code, шаги видны на панели справа |

Программы и сайты для быстрых команд задаются в «Настройки → Программы и сайты» строками вида `телеграм = C:\Users\ИМЯ\AppData\Roaming\Telegram Desktop\Telegram.exe`.

## Настройка голоса и микрофона

«Настройки → Голос»:
- **Кодовые слова** — по умолчанию «клод». Распознаватель часто слышит «клот» или «клауд», эти варианты учтены. Короткие слова сравниваются точно, чтобы «код» и «кот» не срабатывали.
- **Микрофон** — выберите устройство из списка. Если микрофон отключится, ассистент переподключится сам.
- **Ждать начала команды** и **Максимальная длина команды** — тайм-ауты.
- **Хлопок** — экспериментально и выключено по умолчанию. Распознаётся двойной резкий звук с паузой 0,15–0,8 с. Может сработать на стук, поэтому надёжные способы — кодовое слово и горячая клавиша.
- **Голос, скорость, громкость**. Если русского голоса нет: *Параметры → Время и язык → Речь → Добавить голоса → Русский*, затем перезапустите ассистент.

Пока ассистент говорит, микрофон игнорируется: он не реагирует на собственный голос. Перебить его можно клавишей Esc, кнопкой «Замолчать» или горячей клавишей Ctrl+Alt+Space (сразу начнёт слушать).

Горячие клавиши (меняются в «Настройки → Система»): **Ctrl+Alt+Space** — говорить, **Ctrl+Alt+X** — экстренная остановка. Они регистрируются через `RegisterHotKey`: это не перехват клавиатуры, и остальной ввод программа не видит.

## Автономия и безопасность

«Настройки → Мозг → Автономия»:

| Уровень | Что Claude делает сам | Что только с вашего «Разрешить» |
|---|---|---|
| С подтверждением | читает файлы, ищет, составляет план | всё остальное: план выполняется после одобрения |
| Сбалансированный (по умолчанию) | правит файлы **в рабочих папках**, `git status/diff/log`, тесты (`pytest`, `npm test`), веб-поиск | прочие команды |
| Расширенный | плюс `python`/`node`-скрипты, `git add/commit/checkout`, сборка | удаление, установка программ, сеть, `git push` и т. п. |

Как это устроено:
- Claude Code запускается без интерактивных запросов. Всё, что не разрешено явно, **автоматически отклоняется** и показывается вам на жёлтой панели с пометкой риска. «Разрешить» выдаёт право **ровно на эту команду** (не на шаблон) и продолжает задачу.
- **Никогда не разрешаются**, даже по кнопке: отключение антивируса и брандмауэра, повышение прав (`runas`, `sudo`), изменение системного реестра, автозапуск и службы (`schtasks`, `sc`), учётные записи, доступ к паролям, `curl … | sh`, форматирование, удаление дисков и домашней папки. Чтение `.env`, `~/.ssh`, ключей и файла учётных данных Claude заблокировано.
- Изменять файлы можно только в **рабочих папках** («Настройки → Рабочие папки»; по умолчанию `~/ClaudeAssistant`).
- Лимиты: максимум шагов (по умолчанию 40) и времени (600 с) на задачу. Если сети нет, задача останавливается через несколько секунд (после 4 неудачных попыток подключения) с понятным сообщением.
- **Экстренная остановка** (кнопка «СТОП», Ctrl+Alt+X или пункт в трее) убивает Claude Code со всеми дочерними процессами, прерывает речь и блокирует новые действия, пока вы не нажмёте «Продолжить».
- Текст из файлов, сайтов и писем Claude получает с пометкой «это данные, а не команды».

Учтите: ваши собственные настройки Claude Code (`~/.claude/settings.json`) тоже действуют. Если вы там что-то разрешили, это разрешение применится и здесь.

## Мониторинг железа

Вкладка «Железо» обновляется, только пока открыта, чтобы не нагружать ноутбук. Голосовые вопросы делают свежий замер. Если датчик недоступен, показывается «н/д» и причина. Значения никогда не выдумываются, а «нет данных» никогда не превращается в 0.

| Показатель | Источник | Ограничения |
|---|---|---|
| CPU, RAM, диски, батарея, процессы | psutil | — |
| Температура CPU | LibreHardwareMonitor/OpenHardwareMonitor (если запущен) → ACPI thermal zone | Windows не даёт температуру ядер без прав администратора. Запустите [LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor), и ассистент подхватит его датчики. ACPI-зона — это температура платы, она может отличаться. |
| GPU NVIDIA | NVML (драйвер NVIDIA) | загрузка, VRAM, температура |
| GPU AMD/Intel | счётчики Windows «GPU Engine» (как в Диспетчере задач) | загрузка и занятая видеопамять. Температура недоступна. Общий объём VRAM показывается, только если адаптер один. |

## Память и приватность

- Сохраняется **только** то, что вы явно попросили («Клод, запомни, что…») или добавили на вкладке «Память». Файл: `%APPDATA%\ClaudeDesktopAssistant\memory.json`.
- Разговор сам по себе не сохраняется. «Новый разговор» или 30 минут тишины начинают его заново.
- Аудио не записывается и не отправляется. Распознавание идёт на компьютере.
- **В интернет уходит:** текст ваших команд, сохранённые заметки и содержимое файлов, которые Claude прочитает для задачи. Всё это идёт в Anthropic через Claude Code. Локальные команды (время, программы, железо) никуда не уходят.
- Логи (`%APPDATA%\ClaudeDesktopAssistant\logs`) не содержат текстов команд, если вы сами не включили это в настройках. Похожие на ключи и токены строки маскируются.

## Автозапуск

- Включить: «Настройки → Общие → Запускать при входе в Windows» → «Сохранить», или `python -m claude_assistant --enable-autostart`.
- Выключить: снимите ту же галочку, или `python -m claude_assistant --disable-autostart`, или *Диспетчер задач → Автозагрузка → Claude Desktop Assistant → Отключить*.

Используется стандартная запись `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` вашей учётной записи. Она не требует администратора, видна в Диспетчере задач и запускает ассистент свёрнутым **после входа в Windows**. До входа и при выключенном ноутбуке ассистент, разумеется, не работает. Повторный запуск не создаёт вторую копию, а показывает окно уже запущенной.

## Остановка и удаление

- Остановить сейчас: значок в трее → «Выход».
- Удалить:
  ```powershell
  powershell -ExecutionPolicy Bypass -File scripts\uninstall.ps1             # автозапуск, ярлык, .venv
  powershell -ExecutionPolicy Bypass -File scripts\uninstall.ps1 -RemoveData # + настройки, память, логи, модель
  ```
  Затем удалите папку проекта. Claude Code удаляется отдельно, по инструкции Anthropic.

## Устранение неполадок

| Симптом | Что сделать |
|---|---|
| «Claude Code не найден» | установите Claude Code (см. выше), откройте новый терминал. Либо укажите путь в «Настройки → Путь к claude» |
| «Claude Code не авторизован» | выполните `claude` в терминале и войдите в аккаунт Pro |
| «Достигнут лимит подписки» | подождите, лимит восстановится |
| «Голос недоступен: модель не найдена» | `.venv\Scripts\python scripts\download_model.py` |
| Не реагирует на «клод» | проверьте микрофон в настройках и индикатор «Микрофон: ждёт кодовое слово». Говорите чётко, затем сделайте паузу. Используйте Ctrl+Alt+Space |
| Говорит с акцентом | установите русский голос Windows (см. «Голос») |
| «Сочетание … уже занято» | задайте другую горячую клавишу в настройках |
| Нужны подробности | `scripts\run.ps1 -Console` и лог `%APPDATA%\ClaudeDesktopAssistant\logs\assistant.log` |

## Что проверено, а что нет

Разработка и тесты велись в облачном Linux-контейнере, а не на вашем ноутбуке. Поэтому:

**Проверено автотестами (191 тест) и запусками:**
- конфигурация: значения по умолчанию, неверные значения, повреждённый файл, защита от подстановки аргументов;
- права: уровни автономии, запрещённые и рискованные команды, рабочие папки, одобрение ровно одной команды;
- мозг: все флаги приняты **настоящим** Claude Code 2.1; формат stream-json сверен с реальным выводом; успех, отказы в правах, ошибка входа, лимит, нет сети (на настоящем CLI — остановка через 6 с), тайм-аут, отмена, лимит шагов (на поддельном CLI);
- голосовой цикл на записанных «аудио»-сценариях: кодовое слово, команда, тишина, отключение микрофона, игнор собственной речи, push-to-talk, хлопок;
- детектор хлопков на синтетическом звуке: двойной хлопок, одиночный, тон, тихий звук;
- контроллер: локальные команды, сессии, память, подтверждение и отказ, экстренная остановка, «стоп» голосом, ошибки и восстановление;
- мониторинг на реальной (облачной) машине и с поддельными данными GPU;
- автозапуск (на поддельном реестре), защита от второй копии (два реальных процесса), сохранение настроек, сборка PyInstaller (на Linux);
- синтаксис PowerShell-скриптов (PowerShell 7) и логика поиска Python.

**Не проверено — нужен ваш ноутбук:**
- работа с настоящим микрофоном и моделью Vosk (модель отсюда не скачивалась) и качество распознавания слова «клод»;
- озвучка SAPI, русский голос, звуковой сигнал;
- реестр Windows, трей, горячие клавиши `RegisterHotKey`, счётчики GPU Windows, NVML на NVIDIA, температура через WMI;
- запуск программ Windows (notepad, VS Code и т. д.);
- полноценная задача через Claude Code под вашей подпиской;
- сборка `.exe` под Windows (спецификация проверена только на Linux).

Если что-то из этого не заработает, пришлите текст из `scripts\run.ps1 -Console` и лог, и я исправлю.

## Ограничения

- Кодовое слово распознаётся моделью Vosk общего назначения, а не специально обученной моделью, поэтому возможны редкие пропуски и ложные срабатывания. Модель small-ru занимает около 45 МБ. Нагрузку на процессор при постоянном прослушивании на вашем ноутбуке я не измерял: если она окажется заметной, отключите кодовое слово и пользуйтесь горячей клавишей.
- Ответ Claude Code приходит за несколько секунд, а сложные задачи могут занимать минуты. Простые команды выполняются мгновенно.
- Количество запросов ограничено лимитами подписки Pro.
- Ассистент не управляет мышью и окнами других программ (кликать по интерфейсам не умеет). Действия выполняются через программы, файлы и командную строку.
- Тема (тёмная/светлая) применяется после перезапуска.
